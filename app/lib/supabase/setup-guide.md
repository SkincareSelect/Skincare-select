1. Create a Supabase project.
2. Open the SQL editor and run the SQL from schema-extended.sql.
3. Run `supabase/add-missing-product-columns.sql` and `supabase/fix-category-check-constraint.sql` in the SQL editor so admin product fields and categories match the app.
4. Create a storage bucket named product-images with public access.
5. Add your project URL and anon key to .env.local.
6. Restart the Next.js dev server.
